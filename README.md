## 📐 Patrones & Arquitecturas de Software

Alineado con las buenas prácticas de ingeniería, estructuro mis desarrollos basándome en los siguientes patrones arquitectónicos:

*   **Arquitectura Limpia (Clean Architecture):** Separación rigurosa de responsabilidades en capas para lograr software desacoplado y altamente testeable.
*   **Arquitectura Hexagonal:** Aislamiento de las reglas del negocio central mediante puertos y adaptadores.
*   **MVVM / MVC:** Implementación especializada para frontend y desarrollo móvil con Jetpack, asegurando flujos de datos eficientes.
*   **Patrones de Diseño:** Uso consciente de soluciones creacionales, estructurales y de comportamiento (Singleton, Factory, Observer) para resolver problemas complejos con elegancia.
